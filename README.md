# 単位変換 / Units

アメリカ生活で出会う単位をすばやく変換する iPhone 向けウェブアプリ（PWA）です。
Safari で開いて「ホーム画面に追加」すると、アドレスバーのない通常のアプリのように起動し、オフラインでも動きます。

## カテゴリ

| カテゴリ | 主な単位 |
|---|---|
| 長さ | in, ft, ft′in″（身長）, yd, mi ↔ mm, cm, m, km |
| 重さ | oz, lb, 米トン ↔ mg, g, kg, t |
| 体積・容量 | tsp, tbsp, fl oz, cup, pt, qt, gal, ft³ ↔ mL, L, 小さじ・大さじ・カップ（日本）, 合 |
| 温度 | °F ↔ °C, K |
| 面積 | sq in, sq ft, sq yd, acre, sq mi ↔ m², ha, 坪, 畳 |
| 速さ | mph, ft/s, kn ↔ km/h, m/s |
| 燃費 | mpg（米）↔ km/L, L/100km |
| 圧力 | psi, inHg, mmHg ↔ Pa, hPa, kPa, bar, atm, kgf/cm² |
| エネルギー | BTU, therm ↔ J, kJ, cal, kcal, Wh, kWh |
| 仕事率・出力 | BTU/h, hp, 冷凍トン ↔ W, kW, PS |
| 料理 | cup, tbsp, tsp, stick ↔ g（小麦粉・砂糖・バター・米など12種の材料別） |
| 靴のサイズ | US メンズ / レディース, UK ↔ 日本（cm） |

## 使い方

- 上段の単位名をタップすると変換元・変換先を選べます。⇅ で入れ替え。
- 「すべての単位」の行をタップすると、その単位が変換先になります。
- 結果の数字をタップするとコピーします。
- 分数入力に対応しています（`1 1/2` → 1.5）。身長は「フィート＋インチ」で `5 10` と入力します。
- 米国の料理単位では、結果に近い分数（例: ≈ 1 ⅓ cup）も表示します。
- 日本語 / English はホーム画面右上で切り替えられます。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（HTML・CSS・JS をすべて含む単一ファイル、外部依存なし） |
| `manifest.webmanifest` | ホーム画面追加時の名前・アイコン・表示モード |
| `sw.js` | オフライン用キャッシュ（Service Worker） |
| `icon-180.png` / `icon-192.png` / `icon-512.png` | アプリアイコン |

## GitHub Pages で公開

1. GitHub で新しいリポジトリを作成（README は追加しない）
2. 上の 7 ファイルをリポジトリ直下にアップロード
3. Settings → Pages → Source: Deploy from a branch / Branch: `main` / `/ (root)` → Save
4. 表示された `https://ユーザー名.github.io/リポジトリ名/` を iPhone の Safari で開き、共有 →「ホーム画面に追加」

## 更新するとき

`index.html` などを差し替えたら、`sw.js` の `CACHE = 'units-v1'` の数字を上げてください（`units-v2` など）。
インストール済みの端末が次回オンラインで起動したときに新しい版へ切り替わります。

## 換算の前提

- 米国の慣用単位（US customary）。英国のガロン・パイントとは異なります。
- 1 畳 = 1.62 m²（不動産広告の基準）、1 坪 = 400/121 m²。
- 料理の重さ⇔容量は材料ごとの平均的な密度による目安です（±10% 程度）。
- 靴のサイズは大人用の一般的な対応表による目安です。
- 計算はすべて端末内で行われ、データを外部に送信しません。
